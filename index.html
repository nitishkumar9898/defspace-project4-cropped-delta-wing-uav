🧮 Key Formulae

Trim condition: Cm = Cm₀ + Cmα·α + Cmδe·δe = 0
→ δe = −(Cm₀ + Cmα·α) / Cmδe

Lift coeff: CL = CLα·α + CLδe·δe
Level flight speed: V = √(2W / ρ·S·CL)
Drag coeff: CD = CD₀ + k·CL²
Thrust required: Tr = ½·ρ·V²·S·CD
Power required: Pr = Tr · V
k = 1 / (π·AR·e) = 1/(π·3.33·0.89) = 0.1076
